아이디어 작성 요령

작성 전에 확인해 주세요
아이디어명: 아이디어 제목 작성
종류: LEVEL1~3 중 선택

무엇이 문제인가?

문제 작성 시 아래 요령을 참고하여 작성해 주세요.

  1. 5 Whys 기법을 활용하세요.

    표면적인 현상에서 “왜?”라는 질문을 5번 정도 반복하면 본질적인 문제를 찾을 수 있습니다.

  2. 현상 - 원인 - 영향 구조로 작성하세요.
    • 현상: 현재 어떤 일이 벌어지고 있는가?
    • 원인: 왜 그런 일이 발생했는가?
    • 영향: 비용 증가, 시간 낭비, 품질 저하 등 어떤 손해가 발생하고 있는가?

해결 방안

해결 방안 작성 시 아래 요령을 참고하여 작성해 주세요.

  1. [실행 수단/방법]을 통해 [문제 원인]을 해결하고, [목표/기대효과]를 달성한다고 작성합니다.
  2. [대상]에게 [제공하는 핵심 가치/특장점]을 제공하여 [겪고 있던 가장 큰 불편함]을 해결한다고 작성합니다.

아이디어가 구현되었을 때 예상되는 모습

제품 또는 서비스가 실제 구현되었을 때 예상되는 모습, 사용 장면, 개선된 업무 흐름, 기대되는 결과를 구체적으로 작성해 주세요.

공감 순위

관리자 운영 안내

  1. Supabase Table Editor에서 raw_ideas 테이블의 접수 내용을 확인합니다.
  2. 제출자 정보를 제거하거나 문구를 수정해 익명 게시 내용을 만듭니다.
  3. published_ideas 테이블에 익명번호, 제목, 내용, 해결 방안, 예상 모습을 등록합니다.
  4. 등록 즉시 직원 게시판과 순위 화면에 반영됩니다.

아이디어 페스티벌

GitHub Pages + Supabase 버전

우리의 작은 아이디어가 큰 변화를 만듭니다

QR로 접속하여 아이디어를 접수하고, 익명 게시판에서 좋은 아이디어에 공감할 수 있습니다.

운영 흐름

  1. 직원 아이디어 접수
  2. Supabase 원본 테이블 저장
  3. 관리자 익명화 후 게시
  4. 직원 QR 게시판 확인
  5. 사번 입력 후 공감
  6. 공감 순위 확인

보안 원칙

게시판에는 익명화된 데이터만 표시합니다. 원본 성명, 사번, 부서 정보는 게시판에서 읽지 않습니다.

아이디어 접수

입력한 원본 정보는 관리자 익명화 전용으로 사용됩니다.

익명 아이디어 게시판

공감 순위

관리자 운영 안내

  1. Supabase Table Editor에서 raw_ideas 테이블의 접수 내용을 확인합니다.
  2. 제출자 정보를 제거하거나 문구를 수정해 익명 게시 내용을 만듭니다.
  3. published_ideas 테이블에 익명번호, 제목, 내용, 기대효과를 등록합니다.
  4. 등록 즉시 직원 게시판과 순위 화면에 반영됩니다.

정식 운영 시에는 관리자 로그인 화면과 승인 버튼을 추가하는 것이 좋습니다.
